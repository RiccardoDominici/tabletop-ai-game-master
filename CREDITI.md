# Crediti

Questo file elenca i crediti richiesti dalle licenze di musica, suoni, voci, immagini e software usati dal progetto.
I brani e i suoni scelti per le campagne sono elencati nei manifest `campagne/<id>/audio/manifest.json` (il campo `campagna` dice a quale campagna appartengono).
Ogni voce indica il file di origine nel repo, così chi verifica sa dove guardare; dove il repo non scrive un dato, c'è scritto «da verificare» o «non indicato nel manifest».

Campagne considerate: `nozze-neve`, `ponte-lanterne`, `prova-f0`.
