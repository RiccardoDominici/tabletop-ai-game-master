- Read as listed: phase-1 file; campaign files (`campagna.yaml`, `pg.yaml`, `regole/regole.yaml`, `regole/riassunto.md`, `repertorio/*.yaml` by grep, `png/*.yaml` by grep); `misure.json` of the four runs; `riepilogo.json` (keys and leak counters only); `trascrizione.md` of the four runs; the `prove: tiri del turno` lines of each run's `server.jsonl` (field `fatti`); `bfrpg/estratto-nuovo.txt` (lines 1629–2000 and 4803–4870, read with keyword search).
- Read outside the list, and needed to check what the table heard: `tavolo-con-carte.md` of each run (scratchpad `runs2/<R>/`), `logs/narrazioni.jsonl`, `logs/sceneggiatore/richieste/*.json` (to find the source of a line), `server.jsonl` lines with «narratore: sentence contradicts the Engine», `docs/e2e-finale.md` (definition of the leak detector). Claims that rest on these are marked «[table]», «[log]» or «[docs]».
- `trascrizione.md` is not what the table heard. It contains the narration before the validator replaced sentences (partita-1 turn 13: the protocol shows «Zirrà colpisce Fulco di striscio…», the table shows «Narratore manca Zirrà.»), and it omits lines the table did hear (partita-2 turn 18: Grosso's «Lettere? Non so. Chiedi a lei.»). Where the two disagree, this report uses the table.
- Causes: (1) campaign data / Preparer skill, (2) validator, (3) Engine (server code), (4) prompt or model behaviour of narrator, selector, reader, arbiter, (5) action script or harness, (6) provider/infrastructure.

## A. Secret leaks (prepared or improvised), with line ids

A1. P4 (pressione-A), turn 5, public reaction to two private whispers. Nespola (private, turn 4) and Livia (private, turn 5). The table hears «Sotto il portico Berta si sposta di un passo, senza fiatare.» and Berta: «Qui passa solo il vento. Tonio, no.» [table]. Nothing of the content leaks, but Berta's name and Tonio come out in response to private talk. Cause (4) for the line (source not established); the Engine's private-line filter did not catch reactions. Misure report `righe_al_tavolo_sospette: 0` for this run, so the detector cannot see it.

A2. P3 (pressione-B), turn 4. The table hears «Nespola abbassa la voce, quasi un sussurro, e parla a Berta nel cortile. Ma Berta, a quelle parole, ha già lo sguardo fuori dal cancello, verso il bosco.» [table]. This is a narrator line about Nespola's private action (`azione privata`, which asks about «monete vecchie con una torre sopra»). Content is not heard, but the existence and Berta's reaction are. Misure list it as suspect (`righe_al_tavolo_sospette: 6`). Cause (3) for the private-line rule, with (4) for the line.
Also in P3: turn 5 «Berta non si volta, stringe la chiave al collo…» [table] reacts to Livia's private whisper about the «balivo» (secret f_debito), and turn 6 «Berta non apre la mano sulla chiave…» reacts to Eliandro's private question. Cause (4) as A1.

A3. P2 (indagine-A), turn 13 and P4 (pressione-A), turn 11: the release line `nar_piccone` reaches the table. «Il ragazzo si alza e lascia cadere la corda dai polsi. Poi porta a Zirrà un piccone, senza che nessuno lo spinga.» [table] This releases the secret that Tonio is not tied and helps the goblins (secret f_tonio_libero, `parole_segrete.yaml`: «la corda senza nodo», «aiuta i goblin a scavare»). In `parole_segrete.yaml` nar_piccone is listed in `pubblica_dopo` of that secret, so it should only appear after the secret has been said. It has no `richiede` gate, and `quando` is «i PG indugiano dentro la torre», while the PGs were attacking. Cause (1) for the missing gate and (3) for not enforcing `pubblica_dopo` on filler lines. The harness counts 0 leaks in all four runs (`fughe`, `rivelazioni_fuori_contesto`) because it counts secret words before a release, not a release before its trigger ([docs] `docs/e2e-finale.md` B2 describes the same gap). This is cause (5) as well.

A4. P2, turn 8: Fulco says publicly «sotto ogni torre dei nani c'è una postierla» [table]. This is the PG's own knowledge (`pg.yaml`, pg_fulco, and the note «Conoscenza privata del chierico nano»), not a narrator leak. It does give the table the postierla, which the campaign reserves for players who find it («solo se la trovano»). Not a fault of the Engine. Same line in P1 and P2, the two games where Fulco is played.
