# Credits

This file lists the credits required by the licenses for the music, sounds, voices, images and software used by the project.
The tracks and sounds chosen for the campaigns are listed in the manifests `campagne/<id>/audio/manifest.json` (the `campagna` field says which campaign they belong to).
Each entry names the source file in the repo, so anyone checking knows where to look. Where the repo does not record a value, the entry says "to be verified" or "not stated in the manifest".

Campaigns covered: `nozze-neve`, `ponte-lanterne`, `prova-f0`.
