# Il tuo manuale di regole

In questa pagina: dove mettere un manuale di regole tuo, in quali formati, e cosa succede se non ne metti uno.
Prima di leggere: [creare una campagna](creare-una-campagna.md).

## Se non metti nessun manuale

La campagna gioca con l'SRD 5.2 (le regole di D&D libere che il repository porta con sé). Non devi fare nulla.

## Dove metti il manuale

1. Copia il file nella cartella `manuali/` alla radice del repository.
2. Indica il file nel brief della campagna, nel campo `manuale:` (es. `manuale: manuali/il-mio-manuale.pdf`).

La cartella `manuali/` è nel `.gitignore`: i manuali restano sul tuo computer e non entrano mai nel repository,
perché spesso sono protetti da copyright. Solo il file `manuali/LEGGIMI.md` è tracciato.

## Formati accettati

- PDF con testo selezionabile
- Markdown (`.md`)
- Testo semplice (`.txt`)

Un PDF fotografato o scansionato non ha testo: va prima convertito con OCR, o si usa una versione testuale.

## Stato

Questa pagina è un segnaposto: il formato del set di regole e il comando per usarlo arriveranno con la funzione.
Lo schema tecnico è in [docs/regole.md](../regole.md).
